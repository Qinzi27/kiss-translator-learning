# 安装与翻译排错

从 [开始使用](../START-HERE.md) 的 MyMemory 合成句测试开始，可以先区分接口问题与特定网页的扫描问题。离线模式请先完成 [Argos 准备与验证](../offline/README.md)。以下步骤不要求重置全部设置。

## 扩展加载或按钮

| 现象                                 | 检查与处理                                                                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| 找不到 `manifest.json`、无法加载 ZIP | 先解压发布的 Chrome ZIP，选择直接包含 `manifest.json` 的 `chrome` 文件夹。源码根目录不可直接加载，须先构建 `build/chrome`。   |
| 更新后仍是旧界面                     | 确认替换的是浏览器当前加载的目录，在扩展管理页点击重新加载，再刷新阅读页。不要同时保留两个版本在同一网页运行。                |
| 普通网页没有悬浮按钮                 | 刷新网页，确认扩展已启用且有该网站访问权限；检查是否隐藏了悬浮按钮或命中黑名单。也可从工具栏面板切换翻译。                    |
| 本地 HTML 无法翻译                   | 在扩展详情开启「允许访问文件网址」，重新打开文件。浏览器设置页、商店等受保护页面不适合作为测试页。                            |
| 单击只打开菜单，没有立即翻译         | 已保存的旧按钮偏好会保留。先用工具栏面板翻译，或在按钮设置中调整单击动作；升级不会覆盖这类偏好。                              |
| 快捷键无反应                         | 在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 查看快捷键是否被占用或取消。macOS 默认对应 `Option + Q`。 |
| 出现两套译文、关闭后仍有另一套       | 检查是否同时启用其他整页翻译扩展，先只保留一个，再刷新测试页。开发热更新期间出现的异常应在编译稳定后整页刷新重试。            |

## 服务选择与旧译文

服务列表在页面启动时加载。添加新服务后，或者修改同一服务的 Key、地址、模型和偏好后，刷新原阅读页才会生效。在向导中测试成功本身不会自动修改全局服务。

设置全局服务需要 **网页翻译 → 全局规则 → 编辑 → 选择服务 → 保存**。某个网站自己的规则可能覆盖全局规则，可在当前网页面板选择服务。新安装预置与已有设置分开：缺少 MyMemory 时用向导的 **添加到翻译服务**；缺少 Argos 时按离线说明手动添加 Custom，无需清空其他服务。

切换服务后仍显示旧译文，可能是新请求正在进行或失败。将鼠标停在译文处查看错误提示；失败时保留旧文是预期行为。确认新服务可用后，再切换服务或关闭后重新开启。完全关闭翻译应收起该实例生成的译文，不会撤回服务端已经收到的请求。

## MyMemory 与其他在线 API

| 错误或现象                  | 含义与下一步                                                                                                                                   |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| MyMemory 测试按钮禁用       | 当前可能为「仅本机离线」。切到允许在线服务的策略后再主动测试；它不是本机模型。                                                                 |
| MyMemory 提示免费额度/429   | 同一运行环境的待发队列已经停止，至少 60 秒后才接受新的手动请求；每日额度用完可能要等待服务恢复。不会自动重试，不要连续点击或用刷新来规避额度。 |
| MyMemory 添加按钮禁用       | 该预置已经存在，保留了原配置。刷新阅读页面再选择它；若保存过错误配置，在翻译服务中查看该项。                                                   |
| API 返回 401 / 403          | 核对自己的 Key、接口地址、模型权限与地域是否匹配；豆包/腾讯需要自己的接入点或模型服务 ID。登录聊天网页不等于拥有 API 权限。                    |
| API 返回 404 / 不支持的模型 | 核对完整 Chat Completions 地址和控制台实际模型名。自定义 `/v1` 会自动补为 `/v1/chat/completions`，不接受任意 Responses 协议。                  |
| 请求被联网策略拒绝          | 「仅本机离线」不能使用远程 API；「屏蔽谷歌」不能使用谷歌服务。明确选择所需策略与服务，不会自动回退。                                           |
| 超时或网络失败              | 先测试一条合成句，区分接口不可达与原页面过长。已有的成功记录只证明验证当时的网络，不能保证其他地区与运营商可达。                               |
| 标签保留但句子不流畅        | MyMemory、Argos 会分段或按标签边界翻译，可能失去整句上下文。中英混合内容可明确指定源语言；不要把格式保留等同于翻译准确。                       |

费用和账号要求见 [AI 服务说明](../AI-SERVICES.md)。8 家 AI API 的请求与解析有模拟测试，但没有用户真实 Key 的调用记录，不能仅凭预设存在就认为你的账号已开通服务。

## 豆包 / Kimi 后台网页（实验性）

此方式需要已安装扩展，以及同一浏览器用户配置文件中的网站登录状态。普通 Web 开发演示不能代替扩展后台标签功能。

遇到登录、验证码、已有草稿或页面结构变化，任务会停止，并保留专用标签供你查看。先手动处理该标签中的状态，再决定是否重新发起；不要连续发送相同段落。取消后，已经到达网站的请求可能继续生成，并留在聊天历史中。当前只有 DOM 夹具和队列测试，没有真实登录会话验收，因此无法保证当前官网兼容。

发送前还会检查：原输入框仍在页面中、它仍是唯一明确可用的输入框、完整翻译提示未被更改，而且输入区域内只有一个明确发送按钮。网页重绘替换输入框、恢复其他草稿或出现多个发送按钮时会拒绝发送；不会只凭任务标记仍在就发送，也不会到其他区域寻找按钮。出现输入区域无法识别、输入框变化或按钮歧义提示时，手动检查保留的后台标签；不要靠反复点击绕过检查。

## Argos 本机服务

| 现象                             | 检查与处理                                                                                                                                      |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 连接被拒绝、`Failed to fetch`    | 确认已在源码根目录运行 `offline/server.py` 且终端仍开启。访问 `http://127.0.0.1:8765/health`；不可访问时先处理服务启动问题。                    |
| 端口 8765 已被占用               | 可能已有一份服务运行。先检查健康地址，回到原服务终端按 `Ctrl + C` 后再启动；不要盲目终止未知进程。端口在脚本中固定，单改扩展 URL 无法迁移服务。 |
| `/health` 正常但翻译返回 503     | 健康接口不会加载模型。使用本虚拟环境运行 `offline/verify.py`，确认中英和分句模型齐全；缺失时按离线说明联网准备或转移模型。                      |
| 返回 401 `Pairing token required` | 服务已要求配对令牌。本人从服务交互终端或本机 `.offline/pairing-token` 文件复制令牌，填到 **翻译服务 → 本机离线 · Argos → 编辑 → Key**，保存后刷新阅读页。只填令牌，不加 `Bearer `。旧版空 Key 必须更新。 |
| 返回 403 `Loopback Host required` | 使用 `http://127.0.0.1:8765/translate` 或 `http://localhost:8765/translate`，不要使用映射到本机的其他域名、局域网地址或省略端口。 |
| 返回 408 / 413 或连接返回 503 | 正文须在 5 秒内完整送达，最多 80,000 字节；最多 8 个 HTTP 处理连接。停止重复发送，使用默认分段和并发 1，等待当前请求结束。连接限额的 503 与 JSON 模型错误 503 含义不同。 |
| 返回 429「本机模型正在翻译」     | 本机服务一次处理一个请求。扩展该接口的并发设为 1，等待当前任务完成。它与 MyMemory 的每日免费额度不是一回事。                                    |
| 返回 400 / 415                   | 使用本项目 Custom 协议：URL 为 `/translate`，Hook 无需配置、历史文本不会执行；清空不适用的自定义 body/header。服务只接收 JSON，每次 1–8 段、每段不超过 6000 字符。           |
| 返回 403 `Origin is not allowed` | 使用已安装扩展调用。本机服务只允许扩展来源和固定开发来源，不能作为任意网站公开 API。修改浏览器页面端口不等于修改服务允许的来源。                |
| Python 命令或模块不存在          | 确认 Python 3.12 已安装，并使用 `.offline` 虚拟环境自己的 Python 执行脚本；只安装扩展 ZIP 不会安装依赖。                                        |
| 断网后提示禁止出站或缺少模型     | 回到可联网的准备环境补齐并预热，再运行 `verify.py`。不要在离线机反复运行会访问索引的 `prepare.py`。                                             |
| 复制项目到另一电脑后 Python 失效 | 重建目标系统的虚拟环境，不复制旧 `.offline/venv`；模型和分句数据可按离线说明转移。                                                              |

服务地址 `127.0.0.1:8765` 指向当前电脑。把扩展装到另一台电脑并不能使用原电脑的回环地址，需在另一台电脑也准备并启动服务。

服务首次启动生成本机专用令牌，后续重启复用。非交互或重定向输出不会显示令牌，本人用本机文本编辑器读取 `.offline/pairing-token` 即可；不要把文件、令牌截图或完整设置备份放进问题报告。换电脑应生成新的令牌。令牌文件损坏或需要轮换时，先停服务，移走旧文件后重新启动，再更新扩展 Key；无需删除模型。

## 开发页面与提交问题

文档中端口 **4318** 仅用于运行 `pnpm start` 后的 Web 开发演示；不是产品网站或 Argos 地址。未启动开发服务器时打不开是正常现象。`localhost` 与 `127.0.0.1` 的 Web 存储也彼此独立，二者都不等于已安装扩展的存储。

提交问题时提供学习版版本、浏览器与系统版本、联网策略、服务类型，以及能复现问题的一句合成文本。附上错误类型或状态码即可；不要公开 API Key、账号 Cookie、完整设置备份或包含私人内容的请求 URL。先注明问题发生在已安装扩展、Web 开发页还是本机 Python 服务，便于对应验证范围。
